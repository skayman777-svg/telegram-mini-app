DEMOA Telegram Mini App simulated in the browser. This is not real Telegram: payments, the bot and the server are replaced with stubs, orders are fictional.

Telegram Mini App Demo

This is how a coffee shop or store mini app can look inside Telegram: menu, cart, checkout, payment and order statuses. Next to the app you can see what happens behind the scenes: server requests, the payment stub and bot messages.

  1. Open “Cappuccino”, pick a size and milk.
  2. In the cart, apply the promo code BEAN10.
  3. Place the order and click “Simulate successful payment”.
  4. Watch the status in the bot chat and in the event log.
